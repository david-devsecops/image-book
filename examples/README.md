# 예제 프롬프트 모음

『처음 시작하는 AI 이미지 프롬프트』의 코드 블록을 장별로 모았습니다. 실제 실행 프롬프트 21개와 독자 연습·양식 5개가 있습니다. 프롬프트와 결과 관찰은 책 본문에서 가져왔으며, 입력·결과 이미지는 기존 assets 폴더를 연결합니다.

[책 소개](../README.md) · [전체 목차](../TOC.md) · [실제 제작 기록](../pages/093-records.md)

## 처음 사용하는 순서

1. 아래 목록에서 실습을 고릅니다. 처음이라면 [첫 이미지 만들기](ch04-first-image.md)부터 시작하세요.
2. 예제의 입력 항목을 확인합니다. 이미지 편집은 연결된 입력 파일을 열어 원본을 내려받은 뒤 도구에 첨부합니다. 화면 캡처 대신 원본 파일을 사용하세요.
3. 코드 블록 안의 전체 프롬프트를 복사합니다. 양식은 대괄호를 자신의 조건으로 바꿉니다.
4. 생성 결과를 다른 이름으로 저장하고 수록한 관찰 기준과 비교합니다.
5. 마지막의 ‘바꿔 볼 조건’에서 한 요소를 바꾸어 연습합니다.

프롬프트는 이미지 생성 기능이 있는 서비스에서 사용합니다. 코딩, Git 설치, API 키는 필수 준비물이 아닙니다. 전체 자료가 필요하면 저장소의 Code → Download ZIP으로 내려받을 수 있습니다.

## 입력과 결과를 구분하기

조명·배경색 비교는 각 조건마다 같은 원본을 첨부합니다. 지우개 제거, 상자 색 변경, 투명 배경과 카페 글자 추가는 앞 단계 결과를 다음 편집의 입력으로 사용합니다. 스토리보드 두 장면은 텍스트만으로 각각 생성한 사례입니다. 각 예제에 실제 입력 파일을 표시했습니다.

‘실제 실행’은 2026-10-05에 책 제작 중 얻은 결과이며, 이번 예제 모음 추가 작업에서 다시 생성한 것이 아닙니다. 모델 ID가 공개되지 않은 결과에는 미공개로 표시했습니다. 성공한 조건과 남은 문제를 함께 읽으세요. 실험을 해석하는 원칙은 [Chapter 1](../pages/011-ch01.md)에 있습니다.

## 책 본문과 함께 관리하기

프롬프트의 기준 원문은 pages 폴더의 책 본문입니다. 본문을 수정할 때 예제도 함께 갱신하고, 실제 실행 기록과 달라지는 변경은 새로운 실행과 구분합니다. 이 모음은 GitHub에서 실습을 찾는 독자를 위한 보조 자료이며 책의 TOC에는 중복 장으로 넣지 않았습니다. 이용 범위는 [외부 자료와 제작 고지](../THIRD_PARTY_NOTICES.md)를 확인하세요.
