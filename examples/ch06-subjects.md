# Chapter 06 대상과 위치 관계

[예제 목록](README.md) · [책 본문](../pages/021-ch06.md)

## 실습 목표

노트와 연필의 수량과 위치 관계를 설명합니다.

아래 코드 블록의 내용만 복사해 이미지 생성 도구에 입력하세요. 편집 단계에서는 지정한 입력 파일을 먼저 첨부합니다.

## 1. 연습용 요청

상태: 독자 연습용이며, 이 요청의 실제 생성 결과는 수록하지 않았습니다.

입력: 텍스트만 사용합니다.

```text
밝은 나무 탁자 중앙에 닫힌 남색 노트 한 권이 있습니다. 노트 위에는 검은색 연필 하나가 대각선으로 놓여 있습니다. 위에서 수직으로 내려다본 정사각형 사진을 만들어 주세요. 다른 물체와 글자는 넣지 마세요.
```

## 바꿔 볼 조건

노트 색만 바꾸어 보고 연필의 수량과 방향이 유지되는지 확인하세요.

응용 과제는 위에 수록한 실제 실행 기록에 포함되지 않습니다.
