# Chapter 12 필수·선호·제외 조건

[예제 목록](README.md) · [책 본문](../pages/032-ch12.md)

## 실습 목표

한 요청에서 반드시 지킬 조건과 조절 가능한 조건을 구분합니다.

아래 코드 블록의 내용만 복사해 이미지 생성 도구에 입력하세요. 편집 단계에서는 지정한 입력 파일을 먼저 첨부합니다.

## 1. 연습용 요청

상태: 독자 연습용이며, 이 요청의 실제 생성 결과는 수록하지 않았습니다.

입력: 텍스트만 사용합니다.

```text
용도: 가상 머그잔의 상품 소개 이미지.
필수: 잔은 하나이며 전체가 보이고 손잡이는 오른쪽에 있습니다.
선호: 부드러운 아침빛과 차분한 분위기.
제외: 글자, 로고, 사람, 다른 소품.
배경은 무늬 없는 아이보리색으로 해 주세요.
```

## 바꿔 볼 조건

자신의 프롬프트 문장에 필수·선호·제외를 표시하고 충돌하는 조건을 고치세요.

응용 과제는 위에 수록한 실제 실행 기록에 포함되지 않습니다.
