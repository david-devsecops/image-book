# Chapter 17 지우개와 그림자 제거

[예제 목록](README.md) · [책 본문](../pages/042-ch17.md)

## 실습 목표

제거할 대상이 있는 장면을 만든 뒤 지우개와 그림자를 지웁니다.

아래 코드 블록의 내용만 복사해 이미지 생성 도구에 입력하세요. 편집 단계에서는 지정한 입력 파일을 먼저 첨부합니다.

## 1. 노트·연필·지우개 원본

입력: 텍스트만 사용합니다. 첨부 이미지는 없습니다.

```text
밝은 나무 탁자를 위에서 내려다본 정사각형 사진을 만들어 주세요. 왼쪽 위에는 글자와 무늬가 없는 닫힌 아이보리색 노트 한 권, 중앙에는 노란색 연필 한 자루, 오른쪽 아래에는 포장 없는 흰색 직육면체 지우개 하나를 서로 떨어뜨려 놓습니다. 왼쪽 위에서 부드러운 빛이 들어오고 각 물체 오른쪽 아래에 짧은 그림자가 생깁니다. 나뭇결이 자연스럽게 이어지는 탁자입니다. 글자, 로고, 사람, 손, 그 밖의 소품은 넣지 마세요.
```

### 결과 관찰

충족한 조건: 노트는 왼쪽 위, 연필은 중앙, 흰 지우개는 오른쪽 아래에 떨어져 있습니다.

달라진 점: 노트가 화면의 큰 부분을 차지하고, 노란 연필 끝에는 분홍색 지우개가 달려 있습니다.

판정: 제거 연습용 배치 충족.

## 2. 지우개와 그림자 제거

입력 이미지: [desk-base.png](../assets/desk-base.png). 파일을 내려받아 첨부하세요.

```text
첨부 사진의 오른쪽 아래에 있는 지우개와 그 지우개가 만든 작은 그림자만 제거해 주세요. 빈 자리는 주변과 이어지는 탁자 표면으로 자연스럽게 채웁니다. 노트와 연필, 조명, 나머지 탁자 무늬는 유지하세요.
```

### 결과 관찰

충족한 조건: 오른쪽 아래의 흰 지우개와 그 그림자가 사라지고 나뭇결로 채워졌습니다. 노트와 연필은 같은 자리에 있습니다.

달라진 점: 빈 자리에 원래 보이지 않던 나뭇결이 생성됐습니다. 연필 끝의 분홍색 지우개는 제거 대상으로 지정하지 않아 남아 있습니다.

판정: 지정 지우개·그림자 제거 성공, 주요 물체 육안 보존.

## 바꿔 볼 조건
