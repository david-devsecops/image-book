# Chapter 18 참조 이미지의 역할

[예제 목록](README.md) · [책 본문](../pages/043-ch18.md)

## 실습 목표

두 입력 이미지에서 참고할 특성을 구분합니다.

아래 코드 블록의 내용만 복사해 이미지 생성 도구에 입력하세요. 편집 단계에서는 지정한 입력 파일을 먼저 첨부합니다.

## 1. 연습용 요청

상태: 독자 연습용이며, 이 요청의 실제 생성 결과는 수록하지 않았습니다.

준비: 이미지 1은 [가상 잔 원본](../assets/mug-original.png), 이미지 2는 본인이 사용할 권한이 있는 색 분위기 참고 이미지입니다. 이미지 2는 제공하지 않으므로 직접 준비하고 첨부 순서를 확인하세요.

```text
이미지 1의 가상 도자기 잔을 주인공으로 사용합니다. 잔의 형태와 색은 유지하세요. 이미지 2에서는 밝고 차분한 색의 분위기만 참고하고, 이미지 2의 물체와 글자는 가져오지 마세요. 배경은 단순한 실내 벽으로 구성합니다.
```

## 바꿔 볼 조건

이미지별로 가져올 특성 두 가지와 가져오지 않을 특성 두 가지를 적으세요.

응용 과제는 위에 수록한 실제 실행 기록에 포함되지 않습니다.
