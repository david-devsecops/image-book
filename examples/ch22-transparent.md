# Chapter 22 독서 삽화와 투명 배경

[예제 목록](README.md) · [책 본문](../pages/052-ch22.md)

## 실습 목표

삽화를 만든 뒤 배경의 투명도와 그림의 형태 보존을 따로 검사합니다.

아래 코드 블록의 내용만 복사해 이미지 생성 도구에 입력하세요. 편집 단계에서는 지정한 입력 파일을 먼저 첨부합니다.

## 1. 책과 새싹 삽화

입력: 텍스트만 사용합니다. 첨부 이미지는 없습니다.

```text
책 읽기 습관을 설명하는 작은 삽화를 만들어 주세요. 펼쳐진 책 한 권 위에 초록색 새싹 하나가 자라는 모습을 정면보다 조금 위에서 봅니다. 아이보리색 배경에 짙은 남색 윤곽선과 초록색 한 가지 강조색을 쓰는 단순한 평면 일러스트입니다. 그림자는 최소화하고 물체는 화면 중앙에 넉넉한 여백을 두고 배치합니다. 정사각형 이미지이며 글자, 사람, 로고, 다른 장식은 넣지 마세요.
```

### 결과 관찰

남색 선과 초록색 잎이 중심이고, 종이에는 글자 대신 곡선이 그려져 있습니다. 요청은 단순한 평면 표현이었지만 잎 안쪽에는 색의 변화가 남았습니다. ‘평면’이라고 썼다고 완전히 균일한 벡터 도형이 생성된 것은 아닙니다. 파일도 벡터가 아니라 픽셀로 된 PNG입니다.

## 2. 투명 배경 편집

입력 이미지: [reading-illustration.png](../assets/reading-illustration.png). 파일을 내려받아 첨부하세요.

투명 배경 출력을 지원하는 기능을 사용합니다. 실제 실행에서는 투명 배경 옵션을 켰습니다.

```text
첨부한 책과 새싹 일러스트에서 책과 새싹의 형태, 선의 굵기, 색상과 위치를 유지하고 아이보리색 바깥 배경만 제거하세요. 진짜 투명 배경을 가진 PNG로 만들어 주세요. 책의 종이 내부는 아이보리색을 유지하고 투명하게 만들지 마세요. 새싹 잎 안쪽은 초록색으로 유지하세요. 그림자, 체크무늬, 새로운 글자나 물체는 넣지 마세요.
```

### 결과 관찰

바깥 배경은 투명해졌고 책 내부는 밝게 남았습니다. 그러나 원본보다 그림이 화면에서 더 크게 차지하고 윤곽도 달라졌습니다. 따라서 ‘배경 제거 성공, 형태와 위치의 완전 보존 실패’로 평가합니다. 이 사례는 투명도가 맞아도 편집 전체가 성공한 것은 아니라는 점을 보여 줍니다.
