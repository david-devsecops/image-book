# Chapter 23 독서 모임 배경

[예제 목록](README.md) · [책 본문](../pages/053-ch23.md)

## 실습 목표

안내 문구를 나중에 넣을 수 있는 세로 배경을 만듭니다.

아래 코드 블록의 내용만 복사해 이미지 생성 도구에 입력하세요. 편집 단계에서는 지정한 입력 파일을 먼저 첨부합니다.

## 1. 글자 없는 행사 배경

입력: 텍스트만 사용합니다. 첨부 이미지는 없습니다.

```text
가상의 동네 독서 모임 안내문에 쓸 세로 배경을 만들어 주세요. 아이보리색 종이 질감 위에 남색 책 두 권과 작은 초록 잎을 화면 맨 아래에 단순한 일러스트로 배치합니다. 위쪽 3분의 2는 안내 문구를 넣을 빈 공간입니다. 중앙 배경에는 무늬를 최소화합니다. 글자, 숫자, 로고, QR 코드는 만들지 마세요.
```

### 결과 관찰

충족한 조건: 세로 화면 아래에 남색 책 두 권이 있고 위쪽에는 넓은 빈 공간이 있습니다. 글자와 QR 코드는 없습니다.

달라진 점: 작은 잎 하나로 단순화되기보다 여러 잎과 가지가 책 주변에 배치됐습니다.

판정: 안내 배경 조건 충족, 실제 행사 문구 배치는 미실행.

## 바꿔 볼 조건

확정한 행사 문구를 편집 도구에서 배치하고 휴대전화 크기로 읽어 보세요.

응용 과제는 위에 수록한 실제 실행 기록에 포함되지 않습니다.
