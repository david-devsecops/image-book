# Chapter 34 생성·편집 양식

[예제 목록](README.md) · [책 본문](../pages/074-ch34.md)

## 실습 목표

대괄호 안을 자신의 조건으로 바꾸어 요청을 작성합니다.

아래 코드 블록의 내용만 복사해 이미지 생성 도구에 입력하세요. 편집 단계에서는 지정한 입력 파일을 먼저 첨부합니다.

## 1. 새 이미지 생성 양식

상태: 독자 연습용이며, 이 요청의 실제 생성 결과는 수록하지 않았습니다.

준비: 대괄호 안을 실제 조건으로 바꾸세요.

```text
용도: [어디에 사용할 이미지인가]
주인공: [대상, 수량, 중요한 특징]
장소와 배경: [바닥과 뒤쪽 공간]
배치와 시점: [위치, 화면 안의 크기, 바라보는 방향]
빛과 색: [방향, 강도 느낌, 사용할 주요 색]
표현: [사진 또는 삽화, 필요한 표면 특징]
글자: [정확한 문구 또는 글자 없음]
제외: [들어오면 안 되는 요소]
출력 목표: [화면 비율과 쓰임새]
```

## 2. 이미지 편집 양식

상태: 독자 연습용이며, 이 요청의 실제 생성 결과는 수록하지 않았습니다.

준비: 대괄호 안을 실제 조건으로 바꾸세요. 편집 양식에는 사용할 권한이 있는 원본 이미지를 첨부합니다.

```text
첨부 이미지가 편집 대상입니다.
변경: [어느 위치의 무엇을 어떻게 바꿀 것인가]
유지: [모양, 색, 위치, 빛 등 지킬 것]
추가 금지: [불필요한 물체나 문구]
확인할 결과: [사용 목적과 필수 조건]
```

## 바꿔 볼 조건

자주 쓰는 작업 하나를 골라 양식을 다섯 항목 이하로 줄이고 중요한 검수 조건이 남았는지 확인하세요.

응용 과제는 위에 수록한 실제 실행 기록에 포함되지 않습니다.
