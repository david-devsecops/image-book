## 새로 만들 것인지 고칠 것인지

생성은 아직 정해진 원본 이미지가 없는 상태에서 그림을 만드는 작업입니다. 편집은 기존 이미지를 입력하고 일부를 바꾸는 작업입니다. 참조 이미지는 원하는 특성을 알려 주는 자료입니다. 같은 파일이라도 ‘이 잔을 그대로 두고 배경을 바꿔 줘’라고 하면 편집 대상이고, ‘이 사진의 색감을 참고해 다른 장면을 만들어 줘’라고 하면 분위기 참조입니다.

이 구분을 하지 않으면 모델이 보존해야 할 것과 자유롭게 바꿔도 되는 것을 혼동할 수 있습니다. 참조 사진에 사람이 있다고 해서 새 그림에도 그 사람이 들어가야 하는 것은 아닙니다. 색과 조명만 참고하려면 그 범위를 말로 밝혀 주세요.

| 작업 | 입력 | 먼저 정할 것 |
| --- | --- | --- |
| 새 이미지 생성 | 텍스트 요청 | 대상과 목적 |
| 기존 이미지 편집 | 원본 이미지와 요청 | 바꿀 것과 유지할 것 |
| 참조 활용 | 참고 이미지와 요청 | 가져올 특성과 제외할 특성 |

편집 도구의 선택 영역은 수정 위치를 알려 주는 힌트입니다. 수정 뒤에는 선택 영역의 경계와 주변도 확인합니다. 특히 제품의 형상이나 작은 글자가 정확해야 할 때는 원본과 수정본을 나란히 확인해야 합니다.

## 대화도 입력의 일부입니다

같은 대화에서 ‘좀 더 밝게’라고 말하면 직전 결과를 가리키는 것으로 이해할 수 있습니다. 그러나 여러 장을 만든 뒤 ‘이것’이라고만 하면 대상이 모호해집니다. 수정할 이미지를 다시 첨부하고 ‘첨부한 이미지의 배경만’이라고 시작하면 오해를 줄일 수 있습니다.

새 대화에서는 이전 이미지가 자동으로 전달된다고 가정하지 마세요. 원본을 업로드하고 유지 조건을 다시 적습니다. 대화창에 보이는 작은 미리보기만으로는 저장된 원본 파일의 크기도 알 수 없습니다.

독자 과제: ‘다른 잔으로 바꾸기’와 ‘이 잔의 배경만 바꾸기’ 중 자신의 작업이 어느 쪽인지 정하세요. 후자라면 잔의 색, 손잡이 방향, 화면 속 위치를 유지 조건으로 적어 봅니다.
