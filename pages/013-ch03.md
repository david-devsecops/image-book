## 기능을 기준으로 확인합니다

입문 단계에서는 텍스트로 이미지를 생성하고, 이미지를 첨부해 수정하고, 결과를 내려받을 수 있으면 핵심 실습을 시작할 수 있습니다. 모든 서비스에 같은 메뉴나 같은 요금제가 있는 것은 아닙니다. 특정 버튼 위치를 외우기보다 자신이 사용하는 도구에서 세 기능을 찾으세요.

이미지 생성·편집 도구의 발표 사례로는 2025년 12월 16일 공개된 ChatGPT Images 및 API의 GPT Image 1.5, 2025년 11월 20일 발표된 Nano Banana Pro, 2026년 2월 26일 발표된 Nano Banana 2가 있습니다. 세 발표일은 2026년 10월 5일 공식 발표문에서 다시 확인했습니다. 현재 제공 모델의 전체 목록은 아니므로 실제 사용 기능은 계정 화면에서 확인하세요. [OpenAI 발표](https://openai.com/index/new-chatgpt-images-is-here/), [Google Pro 발표](https://blog.google/innovation-and-ai/products/nano-banana-pro/), [Google Nano Banana 2 발표](https://blog.google/innovation-and-ai/technology/developers-tools/build-with-nano-banana-2/).

도구를 정했다면 새 대화를 열어 ‘흰 배경에 파란 원 하나를 그려 주세요’ 같은 간단한 요청으로 이미지 출력 기능이 있는지 확인합니다. 텍스트 설명만 나오면 이미지 기능이 선택되어 있는지 확인하세요. 사용할 수 없는 기능을 프롬프트로 억지로 활성화하려고 반복 요청하지 않습니다.

## 결제보다 먼저 확인할 것

생성 한도, 다운로드 방법, 입력 자료 처리 방침, 편집 지원 여부를 살펴보세요. 채팅 구독과 API 사용료는 별도일 수 있습니다. 이 책은 구체적인 가격을 고정해 제시하지 않습니다. 결제 화면과 공식 요금 안내에서 현재 조건을 확인하고, 처음에는 적은 시도로 목적을 달성할 수 있는지 판단하세요.

공용 컴퓨터에는 계정 정보를 저장하지 않습니다. 회사 사진이나 고객 사진을 올리는 경우에는 개인 계정에서 처리해도 되는 자료인지 먼저 확인합니다. 연습을 위해서는 이 책에 제공된 가상 사물 이미지를 쓰면 입력 자료의 범위를 관리하기 쉽습니다.

독자 과제: 사용 도구, 이미지 생성 가능 여부, 이미지 편집 가능 여부, 저장 방법을 네 줄로 기록하세요. 확인하지 못한 항목은 빈칸 대신 ‘미확인’이라고 적습니다. 그 항목이 필요한 실습에 도착했을 때 다시 확인하면 됩니다.
