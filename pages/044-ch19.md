## 같은 설명이 같은 개체를 보장하지 않습니다

같은 ‘크림색 잔’이라는 말로 여러 번 생성해도 손잡이 모양이나 높이가 달라질 수 있습니다. 연속된 상품 이미지나 캐릭터 장면에서는 이런 차이가 문제가 됩니다. 일관성은 하나의 마법 문구로 해결하기보다 기준과 비교로 관리해야 합니다.

먼저 채택한 기준 이미지를 하나 정하세요. 그 이미지에서 변하면 안 되는 특징을 적습니다. 잔이라면 둥근 손잡이, 원통형 몸체, 크림색 무광 표면이 될 수 있습니다. 캐릭터라면 옷 색, 눈 모양, 몸의 비율을 적습니다. 장면마다 기준 이미지를 다시 제공할 수 있는지 도구의 입력 기능을 확인합니다.

## 고정 항목과 변경 항목

| 고정할 것 | 장면마다 바꿀 수 있는 것 |
| --- | --- |
| 제품의 외형과 주요 색 | 배경의 색과 장소 |
| 캐릭터의 복장과 비율 | 행동과 자세 |
| 시리즈의 선 굵기와 팔레트 | 메시지와 소품 |
| 출력물의 제목 체계 | 각 장면의 설명 문구 |

모든 것을 고정하면 다른 장면을 만들 수 없습니다. 반대로 전부 바꾸면 시리즈라고 느끼기 어렵습니다. 목적에 꼭 필요한 정체성만 고정하고 나머지는 유연하게 다룹니다. 실제 판매 제품은 재질이나 연결부처럼 작은 차이도 중요할 수 있으므로 가상 캐릭터보다 엄격한 기준이 필요합니다.

일부 도구의 시드는 생성 과정의 난수 조건을 지정하는 값입니다. 같은 시드만으로 다른 모델, 설정, 입력에서도 같은 이미지가 나오는 것은 아닙니다. 시드가 없는 도구에서 임의 숫자를 프롬프트에 적는다고 고정 기능이 생기는 것도 아닙니다.
