## 먼저 가상의 의뢰를 읽습니다

작은 카페에서 따뜻한 배 모과차를 소개하려고 합니다. 메뉴판과 SNS에 쓸 수 있는 차분한 이미지가 필요합니다. 촬영된 실물 상품은 없으며, 이번 결과는 교육용 시안입니다. 이 조건을 먼저 적어야 실제 제품을 정확하게 재현해야 하는 작업과 혼동하지 않습니다.

| 항목 | 이번 프로젝트의 결정 |
| --- | --- |
| 대상 독자 | 메뉴를 살펴보는 손님 |
| 전달할 정보 | 메뉴 이름, 분위기, 가상 가격 |
| 주인공 | 투명 유리잔에 담긴 황금색 차 |
| 보조 요소 | 흰 접시 위 배 조각 두 개 |
| 화면 | 세로 4:5를 목표로 요청 |
| 문구 영역 | 상단 40퍼센트의 빈 벽 |
| 제외 | 실제 상호, 로고, 사람, 검증되지 않은 효능 |

메뉴가 따뜻한 음료라고 해서 반드시 증기를 넣을 필요는 없습니다. 증기가 너무 크면 글자 영역을 가릴 수 있습니다. 이미지가 메뉴의 성분이나 맛, 건강 효과를 증명하는 것도 아닙니다. 실제 판매물에서는 제공되는 잔, 양, 재료와 차이가 없는지 별도 검토해야 합니다.

## 완료 조건

첫 이미지에서는 잔 하나, 배 조각 두 개, 제목을 넣을 빈 공간을 확인합니다. 둘째 이미지에서는 문구와 숫자가 정확하고 주인공을 가리지 않는지 확인합니다. 두 파일이 실제로 열리고 파일 속성을 기록할 수 있어야 합니다.

실제 운영에 쓰는 안내라면 추가로 담당자의 메뉴명·가격 확인, 게시할 화면 크기, 이용 권한을 검수해야 합니다. 이 책의 가상 프로젝트에서는 가격이 실제 판매 가격이라는 승인까지 받았다고 간주하지 않습니다.

## 작업을 나누는 이유

처음부터 이미지와 모든 글자를 함께 만들면 배경이 좋은데 숫자가 틀린 상황에서 판단이 어려워집니다. 이번에는 배경을 먼저 채택하고 문구를 추가합니다. 이렇게 나누면 어느 단계에서 오류가 발생했는지 찾기 쉽고, 글자 없는 배경을 다른 안내에도 활용할 수 있습니다.

독자 과제: 자신의 가상 카페를 정하되 실제 상표를 빌리지 않습니다. 음료 하나와 보조 재료 하나만 고르고, 사실 확인이 필요한 문구와 분위기를 설명하는 문구를 구분해 적습니다. ‘기분 좋은 오후’와 ‘질병 예방’은 검수 부담이 같은 표현이 아닙니다.
