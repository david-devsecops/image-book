## 빈칸은 생각을 정리하는 도구입니다

양식을 쓴다고 결과가 자동으로 좋아지는 것은 아닙니다. 필요한 결정을 빠뜨리지 않도록 돕는 것이 목적입니다. 빈칸에 모호한 말만 채우면 긴 요청이 될 뿐입니다. 양식의 모든 항목을 반드시 사용할 필요도 없습니다. 간단한 그림이라면 대상, 배치, 제외 요소 세 줄로 시작해도 됩니다.

### 새 이미지 생성 양식

```text
용도: [어디에 사용할 이미지인가]
주인공: [대상, 수량, 중요한 특징]
장소와 배경: [바닥과 뒤쪽 공간]
배치와 시점: [위치, 화면 안의 크기, 바라보는 방향]
빛과 색: [방향, 강도 느낌, 사용할 주요 색]
표현: [사진 또는 삽화, 필요한 표면 특징]
글자: [정확한 문구 또는 글자 없음]
제외: [들어오면 안 되는 요소]
출력 목표: [화면 비율과 쓰임새]
```

대괄호 부분을 실제 내용으로 바꾼 뒤 실행합니다. 양식의 출력 목표는 도구의 설정을 대신하지 않습니다. 실제 크기를 선택하는 메뉴가 있다면 함께 확인하고 결과 파일을 검사하세요.

### 편집 양식

```text
첨부 이미지가 편집 대상입니다.
변경: [어느 위치의 무엇을 어떻게 바꿀 것인가]
유지: [모양, 색, 위치, 빛 등 지킬 것]
추가 금지: [불필요한 물체나 문구]
확인할 결과: [사용 목적과 필수 조건]
```

‘유지’에 모든 요소를 나열하는 대신 중요한 것을 우선합니다. 얼굴이나 제품 구조처럼 작은 변화도 문제가 되는 대상은 생성형 편집이 적절한 방법인지 먼저 판단해야 합니다.

### 관찰 기록 양식

| 항목 | 기록할 내용 |
| --- | --- |
| 날짜·도구·모델 | 실제 표시값, 모르면 미공개 |
| 입력 파일 | 원본 이름과 사용 근거 |
| 실행 요청 | 전체 프롬프트와 설정 |
| 결과 파일 | 실제 저장된 경로·형식·크기 |
| 충족한 조건 | 결과에서 관찰한 사실 |
| 남은 문제 | 위치와 증상 |
| 다음 행동 | 한 가지 수정 또는 종료 |

## 완성한 예

용도는 독서 모임 공지, 주인공은 펼친 책 하나와 새싹 하나, 표현은 남색 윤곽선의 단순한 삽화입니다. 변경할 요소는 바깥 배경의 투명도이고 유지할 요소는 책의 내부 색과 형태입니다. 실제 결과에서 투명도는 확보했지만 형태가 달라졌다면 기록에도 그 둘을 따로 씁니다. 양식이 결과의 문제를 숨기는 보고서가 되어서는 안 됩니다.

독자 과제: 자신의 가장 자주 쓰는 용도 하나에 맞춰 양식 항목을 다섯 개 이하로 줄입니다. 다섯 개라는 수는 연습을 위한 제한입니다. 필요한 검수 항목까지 삭제하지는 마세요.
