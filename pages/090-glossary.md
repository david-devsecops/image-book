## 요청과 결과를 설명하는 말

| 용어 | 쉬운 풀이와 예 |
| --- | --- |
| 프롬프트 | AI에 전달하는 요청. ‘흰 탁자 위 잔 하나’도 프롬프트입니다. |
| 모델 | 입력을 바탕으로 결과를 만드는 시스템. 서비스 이름과 구분합니다. |
| 생성 | 새 이미지를 만드는 작업. 정해진 원본 없이 시작할 수 있습니다. |
| 편집 | 기존 이미지를 입력해 일부를 바꾸는 작업입니다. |
| 참조 이미지 | 모양·색·분위기 등의 기준을 알려 주는 이미지입니다. |
| 멀티모달 | 텍스트와 이미지처럼 여러 형태의 정보를 함께 다루는 특성입니다. |
| 구도 | 화면 안에서 대상과 빈 공간을 배치하는 방식입니다. |
| 시점 | 물체를 바라보는 위치와 방향입니다. |
| 클로즈업 | 대상을 가까이 크게 보여 주는 표현입니다. |
| 탑다운 | 위에서 수직으로 내려다보는 시점입니다. |
| 여백 | 주인공이나 문구를 돋보이게 하는 비어 있는 공간입니다. |
| 팔레트 | 한 작업에서 사용할 색의 묶음입니다. |
| 무광 | 강한 반짝임이 적은 표면의 느낌입니다. |
| 유광 | 빛이 비교적 뚜렷하게 반사되는 표면의 느낌입니다. |
| 질감 | 표면이 거칠거나 매끄러워 보이는 성질입니다. |
| 확산광 | 넓게 퍼져 그림자 경계를 부드럽게 만드는 빛입니다. |
| 네거티브 프롬프트 | 원하지 않는 요소를 지정하는 요청 또는 전용 입력란입니다. |
| 마스크 | 편집할 위치를 알려 주는 선택 영역 정보입니다. |
| 인페인팅 | 이미지 안의 일부 영역을 새 내용으로 채우는 편집입니다. |
| 아웃페인팅 | 기존 화면 바깥을 새로 만들어 확장하는 작업입니다. |
| 시드 | 일부 도구에서 난수 조건을 지정하는 값. 결과 전체의 보증은 아닙니다. |

## 파일과 활용에 관한 말

| 용어 | 쉬운 풀이와 예 |
| --- | --- |
| 픽셀 | 디지털 이미지를 이루는 작은 점입니다. |
| 화면 비율 | 가로와 세로 길이의 비. 정사각형은 1:1입니다. |
| 해상도 | 문맥에 따라 다르며, 이 책에서는 주로 픽셀 크기를 뜻합니다. |
| PNG | 픽셀 이미지 형식. 투명도를 담을 수 있지만 항상 투명한 것은 아닙니다. |
| JPEG | 사진에 자주 쓰는 압축 이미지 형식입니다. |
| RGB | 빨강·초록·파랑 정보를 조합해 색을 나타내는 방식입니다. |
| RGBA | RGB에 투명도 정보를 담는 알파 채널을 더한 구성입니다. |
| 알파 채널 | 픽셀의 투명도를 담는 정보입니다. |
| 래스터 | 픽셀로 구성된 이미지. PNG와 JPEG가 대표적인 예입니다. |
| 벡터 | 점·선·면의 수학적 정보로 표현하는 방식. 단순한 그림이라고 자동으로 벡터가 되지는 않습니다. |
| 업스케일 | 이미지의 픽셀 수를 늘리는 처리. 새로 추정한 세부가 생길 수 있습니다. |
| 크롭 | 화면의 일부를 잘라 내는 작업입니다. |
| ppi | 1인치 길이에 배치하는 픽셀 수입니다. |
| 메타데이터 | 파일의 제작·크기·촬영 조건 등 부가 정보입니다. |
| 스토리보드 | 이야기의 장면과 순서를 계획한 그림입니다. |
| 인포그래픽 | 정보의 관계나 순서를 그림과 배치로 설명한 자료입니다. |
| 라이선스 | 자료를 사용할 수 있는 조건을 정한 허락입니다. |
| API | 프로그램이 서비스의 기능을 호출하는 통로입니다. |

모르는 용어를 만나면 정의만 외우지 말고 자신의 이미지에서 어느 부분을 가리키는지 찾아보세요. 무광은 표면에, 여백은 배치에, 알파 채널은 파일 속성에 해당합니다. 서로 다른 층위의 말을 구분하면 오류를 고칠 도구도 고르기 쉬워집니다.
